About the Project

About SiteSpy

SiteSpy is a mobile-first construction project records and cost estimation app built with Expo React Native, Firebase, and Firestore. It helps construction teams capture measurements, estimate material costs, organise site records, and review project history on any device — even in low-connectivity field conditions.

My Contribution

My Contribution

I owned the create and edit project workflow in SiteSpy. This includes NewProjectScreen.js where users start a new construction project record, EditProjectScreen.js for updating existing records, and projectService.js for the Firestore read and write operations behind both screens. Making the create/edit flow simple and reliable is critical because it is where users commit their real project data.

Reflection

My Reflection

Building a create/edit workflow that handles both new records and existing ones cleanly requires careful state management. I learned how to pre-populate forms from Firestore documents without causing stale data issues, and how to give the user clear feedback during save operations. Error recovery — what happens when a write fails mid-way — was the hardest part.
